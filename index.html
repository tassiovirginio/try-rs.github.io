CLI Commands

You can also bypass the UI and use direct commands:

Command Description
try-rs Opens the TUI interface.
try-rs <name> Create (or jump to) a named experiment.
try-rs <url> Clones a repository into a dated folder.
try-rs <url> <name> Clones a repository into a specific folder name.
try-rs -s <url> Shallow clone (depth 1) for fast experiments.
try-rs -w <name> Create a git worktree from the current repository.
try-rs --setup <shell> Setup shell integration (fish, zsh, bash, power-shell, nu-shell).
try-rs --version Show application version.
try-rs --help Show help message.

Tip: You can use the alias try after configuring shell integration.

Everything try-rs can do

A robust feature set built for speed and organization.

Instant Workspaces

Generate isolated environments in milliseconds. No more cluttering your /tmp manually.

Fuzzy Filtering

Start typing anywhere in the TUI. Built-in fuzzy matching helps you find projects instantly.

Git Integration

Provide a GitHub URL. try-rs clones it into a new dated folder and drops you in the shell.

Interactive TUI

A beautiful Ratatui-powered terminal interface. Browse experiments with zero latency.

Safe Cleanup

Delete old workspaces directly from the interface with Ctrl+D.

Editor Launch

Open your favorite IDE instantly in the workspace using the Ctrl+E shortcut.

Themes

Configuration

Customize your experience by creating a config.toml file.

Linux
~/.config/try-rs/config.toml
macOS
~/Library/Application Support/try-rs/config.toml
Windows
%AppData%\try-rs\config.toml
